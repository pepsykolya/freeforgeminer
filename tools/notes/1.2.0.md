- **New fused GPU kernel** (int8 tensor cores, layer reduce in registers, intermediate sums never leave the chip):
  - RTX 3070: 14.9 → **20.0 FW/s** (+34 %, GPU benchmark); on a pool 20.6 FW/s.
  - RTX 4070 Ti: 26.1 → **32.4 FW/s** (+24 %, GPU benchmark); on a pool 25.6 → **30.5 FW/s**.
- Bit-exact with the reference (determinism and digest checks), ~4× less GPU memory.
- RTX 30/40/50 (sm_80+) use the new kernel; older GPUs keep the previous path. `CMFD_FUSED=-1` restores the old kernel.
- The new kernel loads the GPU more densely: after updating, watch the log for `INTEGRITY | ok` and no rejected/invalid shares.
