- **Per-GPU tuning**: the GPU worker now picks its kernel tile configuration automatically from the GPU L2 cache size. RTX 30 get a better rasterization; RTX 40/50 keep the RTX 4070 Ti configuration.
- **New `speed` / `eco` modes** (default `speed`): HiveOS Extra config `"mode":"eco"`, Windows `MODE` in `start.bat`, or `CMFD_MODE`.
- **RTX 3070** (core lock 1560 MHz, +175, memory stock, pool, 8-min windows): 1.2.1 = 19.8 FW/s @ 172 W (11.5 FW/s per 100 W); 1.2.2 speed = 19.6 FW/s @ 166 W (11.8); 1.2.2 eco = 18.3 FW/s @ 143 W (12.8).
- Output bit-identical to the reference, determinism 0/32. New overclocking notes in the manual: keep memory at stock (memory locked at 810 MHz drops to ~3.5 FW/s) and a core offset stable for other coins may be unstable for CMFD.
- Windows: `start.bat` has `MODE` and the default pool is now Aria.
