- **Compact-mainnet fork compatibility.** The Common Foundry mainnet will switch to compact proofs at height 67,535; the network ID stays, the consensus fingerprint changes from `e9d81f15…` to `9009948f…`. The pool client now accepts exactly these two fingerprints (selected at the pool's auth challenge, echoed in `hello`, required unchanged in `hello_ack`; anything else is refused before signing). Ported from the official reference miner (mainnet-compact-v1.0.21-rc.2 / 1.0.22). Also for the dev-fee session. `Pool consensus fingerprint: …` is logged on every connect; `cmfd-miner pool-compatibility-info` prints the accepted pins.
- Mining code, kernels and hashrate are the same as 1.2.4. Not verified against a pool that already runs the new fingerprint (none was available); verified against the current pool and with loopback tests for both identities.
