- **Faster GPU kernel**: about half the instructions in the main loop and in the epilogue (Montgomery arithmetic in a scaled domain, strength-reduced addressing). New **persistent kernel** (dynamic tile scheduling, next tile prefetched during the epilogue, alternating K direction) for `eco` on RTX 30 and for both modes on RTX 40/50.
- **Pipelined pool mining**: the GPU no longer waits while the pool verifies a share; every share of a batch is sent and no nonce is searched twice. On a pool with frequent shares the GPU used to stand idle 13-20 % of the time; now 0 %. The hashrate in the log is measured over wall time.
- **RTX 3070** (core lock 1560 MHz, +175, memory stock, pool): speed 20.3 FW/s @ 179 W, eco 19.9 FW/s @ 156 W. When the card runs at its power limit choose `eco` (135 W limit: +15 %).
- **RTX 4070 Ti** (core lock 2100 MHz, +150, 190 W, pool): 35.1 FW/s @ 179 W (1.2.2: 30.6 FW/s @ 190 W in the GPU benchmark). Best profiles: core lock 2400 MHz + 220 W limit = 39.5 FW/s @ 199 W, core lock 2250 MHz + 190 W = 37.3 FW/s @ 188 W. Full table in the manual, section 7.
- Output bit-identical to the reference (RTX 3070 and RTX 40), 0 rejected shares in pool tests. Windows build included.
